# פירוק-קדימה ולוח פרויקט משותף

מסמך זה מתאר את היכולת שנוספה למסך קלוד באפליקציה: לקחת צ'אט "תוכנית כללית"
ולפרק אותו **קדימה** לכמה צ'אטים-חלקים מקושרים, עם **לוח פרויקט משותף** שכל
חלק קורא ממנו **לפי דרישה**.

## הרעיון (במילים פשוטות)

מתחילים צ'אט אחד — "התוכנית לדף הסטודיו". ממנו פותחים בכוונה כמה חלקים:
עיצוב, תוכן, וכו'. כל חלק הוא צ'אט משלו, אבל:

- **הוא לא מתחיל ריק** — הוא מקבל תדריך פתיחה (`seed_context`): מה החלק שלו,
  מה כבר סוכם בתוכנית שרלוונטי אליו, ואיפה הלוח המשותף.
- **הוא מקושר לתוכנית** (`parent_thread_id`) — אפשר לקפוץ ממנו חזרה לתוכנית
  ובין החלקים.
- **הוא לא "צופה בזמן אמת" בחלקים האחרים** — שתי שיחות הן שתי שיחות. במקום זה
  יש **לוח פרויקט משותף**: כל חלק רושם בו החלטות/התקדמות, וחלק אחר קורא אותו
  **רק כשמבקשים** ("צרף את הלוח להודעה הבאה").

## ההבדל מ"פיצול" (split) הקיים

| | פיצול (split) | פירוק (decompose) |
|---|---|---|
| מתי | **בדיעבד** — שיחה שהתפזרה לכמה נושאים | **קדימה** — תוכנית שמפרקים ביודעין |
| מה קורה לתורים | **עוברים** לצ'אט החדש (מקופלים במקור) | **נשארים** — התוכנית שלמה |
| הצ'אט החדש | מקבל טקסט מסירה או fork מלא | מקבל תדריך פתיחה לחלק שלו |

שתי היכולות חיות זו לצד זו. הפיצול נשאר לשיחה שנדדה; הפירוק הוא לתכנון מכוון.

## הלוח המשותף

- נשמר כ-Markdown ב-`claude_threads.project_board`, על **שורש הפרויקט** (האב
  העליון ביותר, שמגיעים אליו בטיפוס במעלה `parent_thread_id`).
- **קריאה לפי דרישה בלבד**: מתג בפאנל הפרויקט מזיין את "צרף את הלוח להודעה
  הבאה". רק אז ההודעה נשלחת עם הלוח מוזרק לפרומפט (תור אחד, ואז מתאפס). הלוח
  **לעולם לא נשלח אוטומטית** — זו החלטת המשתמש (שליטה מלאה).
- **כתיבה**: עריכה ידנית של הלוח, או כפתור "סכם את השיחה הזו ללוח" שמריץ סיכום
  קצר (על המנוי — אפס טוקני API בתשלום) ומוסיף רשומה מתוארכת (שעון ניו יורק).

## איפה זה בקוד

- **מיגרציה**: `supabase/migrations/20260728200000_claude_project_decompose_and_board.sql`
  — מוסיף `'decompose'` ל-CHECK של `claude_thread_analyses.kind`, ומוסיף
  `project_board` + `project_board_updated_at` ל-`claude_threads`.
- **Backend**: `server/src/modules/claude/analysis.ts`
  (`runDecomposeAnalysis`, `applyDecompose`) +
  `server/src/modules/claude/threads.ts` (נקודות קצה + `resolveProjectRoot` +
  הזרקת הלוח ב-`/messages`).
- **Frontend**: `src/components/claude/ProjectPanel.tsx` (כניסה אחת מכווצת
  לפי כלל ה-UI המצומצם), `DecomposeReview.tsx`, וחיווט ב-`ClaudeChat.tsx`.
