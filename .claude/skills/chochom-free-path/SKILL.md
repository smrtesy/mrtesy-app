## מה עושים
החיסון מפני סיכון-המוניטין: בהתחלה כל פתרון-חינם ממתין לאישור חנוך לפני שליחה. ה-QC מסנן; חנוך פוסק.
1. **תוכן הפתרון:** מדריך **מדורג צעד-אחר-צעד** מותאם לרמת האדם (מתחיל→סגנון-הבית: ממוספר, לינק עמוק, בלי ז'רגון) — לא "גישה". עד תקרת-DIY מדריך מלא; מעל התקרה מסגרת+הצעת-סשן.
2. **מסך-חשיבה חי** (בשני המצבים): צעדים אמיתיים (זיהוי→שליפה→סיווג), ~60–90ש', בלי ספינר מזויף.
3. **סקירה-אנושית (ברירת מחדל):** טיוטה → אישור חנוך → מייל + **PDF מלא** (הסתייגות קצרה); בדפדפן אישור-קבלה מיידי. מתג auto_send (כבוי; מופעל אחרי הפיילוט) → תמצית מיידית בדפדפן + מייל+PDF.
4. כל פלט מסומן כתוצר-AI + הסתייגות (רף-האיכות). תעד כל פנייה+פתרון. הרץ מקצה-לקצה בשני המצבים.

- אישור-עלות לפני כל הרצה בתשלום (עד $5 בתקציב-שלב מאושר → "כן" בסשן; מעל → משימת-אישור).
